# WEARABLES - Basic React E-commerce Project

Beginner-friendly React project using Vite, FakeStore API, useState, useEffect, components, props and React Router.

## Run the project

1. Extract the ZIP file.
2. Open the `WEARABLES_Project_Files` folder in VS Code.
3. Open the terminal in that folder.
4. Run `npm install`.
5. Run `npm run dev`.
6. Open the localhost URL shown in the terminal.

## Features

- Fetches products from FakeStore API.
- Displays products in a reusable table.
- Add products to cart; repeated adds increase quantity.
- Increase or decrease quantity in cart.
- Delete cart items.
- Calculates total price.
- Navigate between Products and Cart pages.

## Main files

- `App.jsx`: cart state and cart functions.
- `Header.jsx`: navigation bar.
- `Products.jsx`: API call and products page.
- `Table.jsx`: reusable products table.
- `Cart.jsx`: cart page, quantity edit, delete and total.
